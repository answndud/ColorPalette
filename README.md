# 🎨 Color Palette Generator - 색상 팔레트 생성기

디자이너와 개발자를 위한 색상 팔레트 생성 도구입니다.

## ✨ 기능

- 🎯 **메인 컬러 선택**: 컬러 피커 또는 HEX 코드 직접 입력
- 🌈 **색상 조화 자동 생성**: 보색, 유사색, 삼색 조화, 분리보색
- 🎨 **명도 변화**: 10단계 Shades & Tints 자동 생성
- 🔄 **색상 값 변환**: HEX, RGB, HSL 상호 변환
- ♿ **WCAG 접근성 체크**: 대비율 자동 계산 (AA/AAA 등급)
- 💻 **CSS 변수 코드 생성**: 복사해서 바로 사용 가능
- 🌓 **라이트/다크 모드**: 원클릭으로 테마 변경

## 🌈 색상 조화 종류

| 조화 유형 | 설명 |
|----------|------|
| 보색 (Complementary) | 색상환에서 180° 반대 위치 |
| 유사색 (Analogous) | ±30° 인접한 색상 |
| 삼색 조화 (Triadic) | 120° 간격의 3색 |
| 분리보색 (Split-Complementary) | 150°, 210° 위치의 색상 |

## ♿ WCAG 접근성 등급

| 등급 | 대비율 | 용도 |
|------|--------|------|
| AA Large | 3:1 이상 | 큰 텍스트 (18pt+) |
| AA | 4.5:1 이상 | 일반 텍스트 |
| AAA | 7:1 이상 | 향상된 접근성 |

## 💻 생성되는 CSS 변수

```css
:root {
  --color-primary: #6366F1;
  --color-primary-rgb: 99, 102, 241;
  --color-complementary: #F1EF63;
  --color-analogous-1: #6366F1;
  --color-analogous-2: #9F63F1;
  --color-50: #F5F5FF;
  --color-100: #E0E1FF;
  /* ... */
  --color-900: #1E1F5C;
}
```

## 🚀 사용 방법

1. 컬러 피커로 메인 색상 선택 또는 HEX 코드 입력
2. 자동 생성된 팔레트 확인
3. 색상 카드 클릭하여 HEX 코드 복사
4. CSS 변수 코드 전체 복사하여 프로젝트에 적용
